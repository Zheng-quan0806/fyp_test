Notebook Tutor

Notebook Tutor is an educational note-taking application developed as a Final Year Project. It helps students organize notes, draw and annotate pages, import learning materials, and manage their study activities.

Main features

  • Digital notes, folders, drawing tools, comments, images, and PDF import
  • AI-assisted learning and saved AI conversation history
  • Private and group community chats
  • Calendar tasks and reminder notifications
  • Study-time tracking and motivational streaks
  • Optional cloud synchronization through Supabase
